# Python deps layered ON TOP of the rocm/pytorch base image's ROCm (HIP) torch build.

# !!! DO NOT add torch / torchvision / torchaudio here. !!!

# pip *constraint* pinning torch to the exact build already present (`-c torch-constraint.txt`),

# If you upgrade the base image's torch, bump these to the matching torchrl/tensordict release.
